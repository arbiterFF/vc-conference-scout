Note: many conference sites load their attendee list with JavaScript (Map-Your-Show, 6Connex, etc.) — those won't work with URL scraping. If the scan fails, copy the company list into a CSV and use the CSV upload tab instead.

Optional. If auto-detect fails, inspect the page in your browser and provide a CSS selector pointing at company names.

CSV format requirements:
  • Comma-separated, with a header row in the very first line.
  • One column should contain the company names — name it name, company, exhibitor, organization, or attendee. The parser auto-detects which column to read.
  • No leading empty columns or sheet-title rows. If you exported from Numbers/Excel, delete the auto-prepended title row first.
  • Other columns (descriptions, booth numbers, etc.) are ignored.
